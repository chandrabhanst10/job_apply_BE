# Folder Structure

- `src/config`: environment and logger configuration.
- `src/database`: MongoDB connection lifecycle.
- `src/models`: Mongoose schemas.
- `src/repositories`: database access.
- `src/services`: business logic.
- `src/modules`: feature controllers.
- `src/routes`: route composition.
- `src/middleware`: reusable HTTP middleware.
- `src/validations`: Zod request schemas.
- `src/ai`: Gemini and local resume analysis.
- `src/docs`: OpenAPI spec.
- `src/uploads`: tracked upload directory placeholder.
- `tests`: Vitest and Supertest coverage.
